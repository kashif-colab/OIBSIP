\# To-Do App with Login



\## Oasis Infobyte Android Application Development Internship



\### Task 2 — To-Do App with Login



A simple Android To-Do application developed as part of my Android Application Development internship at Oasis Infobyte.



\## Features



\- User registration and login

\- Password hashing using SHA-256

\- SQLite database for storing users and tasks

\- User-specific task management

\- Add tasks with optional notes

\- Mark tasks as completed

\- Delete tasks

\- Logout functionality

\- Login session management

\- Input validation



\## Technologies Used



\- Java

\- XML

\- Android Studio

\- SQLite

\- Android SDK



\## Project Structure



The application includes:



\- Login screen

\- Create Account screen

\- To-Do List screen

\- Add Task dialog

\- Task completion and deletion

\- SQLite database
