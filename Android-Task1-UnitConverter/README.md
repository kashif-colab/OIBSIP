\# Unit Converter App



An Android Unit Converter application developed as part of the Oasis Infobyte Android Application Development Internship.



\## Features



\- Convert Length units

\- Convert Weight units

\- Convert Temperature units

\- Source and target unit selection using Spinners

\- Input validation using Toast messages

\- Result displayed clearly after conversion



\## Supported Conversions



\### Length

\- Meters

\- Kilometers

\- Centimeters

\- Miles



\### Weight

\- Kilograms

\- Grams

\- Pounds



\### Temperature

\- Celsius

\- Fahrenheit

\- Kelvin



\## Technologies Used



\- Java

\- XML

\- Android Studio

\- Android SDK



\## How to Run



1\. Open the project in Android Studio.

2\. Allow Gradle synchronization to complete.

3\. Start an Android emulator or connect an Android device.

4\. Run the application.
